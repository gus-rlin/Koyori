# Stage-four evidence for AWS Builder and Open Source

Prepared on 2026-10-06 from JRN-021 and the checked-in channel contracts. This English evidence draft separates observed local behavior, infrastructure preparation and unexecuted cloud qualification. No contest eligibility is inferred.

Observed frictions: checkout disappearance before resuming (cause unknown, recreated isolated checkout), blocked Windows pytest launcher (module invocation works), SDK transport/identity defaults, concurrent session activity conflict (bounded fresh retries), and TLS certificate trust during image builds (approved public CA via BuildKit secret; TLS remains enabled). A real TCP MCP test also exposed an external conversion of a fixed-length HTTP body into invalid chunks, absent inside Docker Linux. Letting the ASGI host frame the response resolved initialization, discovery and authentication denial; the external component causing the conversion is unknown. These are observed environment/integration issues, not attributed SDK vulnerabilities.

The independent reviewer initially scored the implementation 7.5/10 and found missing Lambda startup environment and IAM conditions, a concurrent memory-erasure disclosure window, an incomplete erasure ledger and misleading speech templates. The main agent alone corrected them and added targeted regressions. The second review reached **9/10**, with 75 independently executed targeted tests and no remaining material finding. The final cumulative suite passed **297 tests**, with zero failures/errors/skips. These results qualify local implementation and deployment preparation only. Source guards and synthesized role assertions are useful practices to reuse: a successful local suite or CDK synthesis alone had missed the startup and deletion windows.

All four cumulative Docker recipes passed on the rebuilt final sources; 47 application modules match the Lambda bundle and AMD64 runtime, and the 72 Linux dependencies have no known audit finding. ARM64 builds successfully but has not been executed natively. The 17 mixed localhost MCP/session samples measured p50 58.64 ms and p95 197.11 ms; these are not speech latency. The GitHub workflow was prepared but not executed in this task. Aggregate fingerprints and qualified/not-qualified flags are in [artifact-evidence.json](artifact-evidence.json).

Costs: not measured; zero model calls in local voice recipes. No AWS resources were created in this task. Synthesized Lambda, AgentCore, AppSync, CloudWatch and IAM resources are deployment preparation, not actual AWS usage. Fourteen containers and five volumes remain in the isolated local `koyori-stage4` project; exact endpoints and shutdown instructions are recorded in JRN-021.
